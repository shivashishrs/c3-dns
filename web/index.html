C3-DNS installer

A network-wide DNS ad blocker for the ESP32-C3. Plug in the board, press Install, then set it up from your phone.

1. Install

Connect an ESP32-C3 board with 4 MB flash by USB, then:

This browser cannot talk to USB devices. Use Chrome or Edge on a desktop or laptop (Windows, macOS, Linux). USB access needs HTTPS or localhost.

First install: choose Erase device when asked. Updating later without erasing keeps your Wi-Fi, password and rules.

No port in the list? Hold the board's BOOT button while plugging it in, then try again. On Linux, add yourself to the dialout group.

2. Set it up

  1. On a phone or laptop, join the open Wi-Fi network C3-DNS-XXXX that the board starts.
  2. Most phones open the setup page by themselves; if yours does not, open http://192.168.4.1/.
  3. Choose your home Wi-Fi and an admin password (12+ characters). The board restarts and joins your network.

The setup network closes after 15 minutes. Hold BOOT for 5 seconds to start over.

3. Use it

  1. Open http://adblock.local/ (or the board's address from your router) and sign in as admin.
  2. In your router's DHCP settings, set the board's address as the DNS server. Give the board a fixed address (DHCP reservation) first.
  3. Test from any device: nslookup doubleclick.net <board-ip> should answer 0.0.0.0.
